# supabase – Veritabanı (Sorumlu: C)

Tablolar SQL dosyaları olarak `migrations/` altında tutulur (tarih sıralı).

İlk tablolar (taslak):
- `profiles` – kullanıcı ve aile üyesi profilleri (ad, cinsiyet)
- `measurements` – profil başına boy, göğüs, bel, kalça
- `products` – eklenen ürünler (tür, görsel, kaynak link)
- `size_charts` – ürün başına beden tablosu (beden, boy, en, kol)
- `favorites` – favoriler
